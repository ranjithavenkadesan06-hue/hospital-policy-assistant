# hospital-policy-assistant# Hospital Policy Assistant

## 📌 Project Description
This project is a Retrieval-Augmented Generation (RAG) based assistant that answers user queries from hospital documents such as brochures, policies, and patient instructions.

## 🎯 Features
- Upload and read PDF documents
- Extract and process text
- Answer questions based on documents
- Simple chat interface (to be implemented)
- Retrieval-based responses

## 🛠️ Tech Stack
- Python
- FastAPI (backend)
- Streamlit (frontend)
- LangChain (RAG pipeline)
- FAISS (vector database)

## ⚙️ Setup Instructions

1. Clone the repository  
2. Install dependencies:
pip install -r requirements.txt  

3. Run the project:
python app.py
